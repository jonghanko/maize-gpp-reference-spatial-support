# Source and implemented-software citations

The main input experiments use the stated AmeriFlux FLUXNET-1F v1.3_r1 records. US-IAC belongs to the separate supporting cohort. Dataset creator strings below follow the acquired/current provider citation; Ro1 Tim/Timothy and IAC name-field anomalies have not been repaired. DOI registration-level years can differ from the provider's version-specific citation year.
